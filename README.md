# Cybersecurity-Python-Tools

This repository contains Python scripts and tools for cybersecurity tasks that I am developing, covering log analysis, indicator of compromise handling, network utilities, and automation.

## Status

This project is in progress. Scripts are added only once they have genuinely been written and tested.

## Structure

log-analysis/ will contain scripts for parsing and analysing security logs. ioc-tools/ will contain scripts for handling indicators of compromise. network-tools/ will contain scripts for network analysis and utilities. automation/ will contain scripts that automate repetitive security tasks.

## Skills being developed

Python, log analysis, network security, and security automation.
